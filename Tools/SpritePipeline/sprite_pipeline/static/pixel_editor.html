精确规则

  • 一格就是 PNG 的一个原始像素
  • 铅笔直接替换 RGBA，不做抗锯齿
  • 橡皮擦写入透明黑色 (0,0,0,0)
  • 网格、选区和洋葱皮不会写进 PNG
  • 填充只匹配四向连通且 RGBA 完全相同的像素
